# Rafsan Haque Portfolio

One-page video portfolio, hosted on Vercel. Every push to `main` goes live automatically.

- `index.html`: the page (title top left, Short form and Long form tabs).
- `videos.js`: the video list. Vertical videos go under Short form, horizontal under Long form, sorted automatically.

Vercel settings: Framework Preset "Other", no build command, root directory left as is.
